# KPI指标用户 - 使用帮助

## 功能概述
KPI指标用户模块用于配置参与KPI考核的用户及其指标信息，包括分配考核组、配置指标、设置计算类型和SQL配置等。

## 界面说明
- **黄色背景**：手填数据行
- **白色背景**：自动计算数据行

## 主要功能

### 1. 搜索筛选
- **用户名**：按用户名搜索（支持拼音匹配）

### 2. 用户管理
#### 新增用户配置
1. 点击「新增」按钮
2. 在弹出的对话框中选择用户
3. 选择考核组（组织节点）
4. 配置一个或多个指标
5. 保存配置

#### 编辑用户配置
1. 点击操作列的「编辑」图标
2. 修改用户的指标配置、计算类型、通知人等
3. 保存更新

#### 删除用户配置
> ⚠️ **警告**：删除用户会删除该用户的全部指标数据！

1. 点击「删除」图标
2. 确认删除操作

### 3. 生成指标数据
1. 点击「生成指标数据」图标（日历图标）
2. 在对话框中选择一个或多个月份
3. 确认生成
4. 系统会为该用户在所选月份生成月度指标数据

### 4. 计算类型说明
- **累计模式**：计算从1月到当前月的累计值。例如6月查看5月数据，会统计1-5月总和
- **当月模式**：仅计算当前月的数据。例如6月查看5月数据，只统计5月数据
- **自定义模式**：根据特定指标的特殊需求进行自定义计算
- **混合模式**：多种计算方式混合使用

## 表格字段说明
- **序号**：按用户分组的序号
- **工号**：用户工号
- **用户名**：被考核用户
- **考核组**：所属组织节点
- **指标编号**：KPI指标编号
- **指标类型**：指标类型（如销售额、利润等）
- **考核指标**：指标名称
- **实际值**：配置的SQL用于计算实际值
- **达成率**：配置的SQL用于计算达成率
- **计算类型**：累计/当月/自定义/混合模式
- **通知人**：绩效通知发送对象
- **操作**：编辑、生成指标数据、删除

## 常见问题

**Q: 什么是手填数据和自动计算数据？**
A: 手填数据需要手动输入目标值和完成值，自动计算数据通过配置的SQL自动计算。

**Q: 一个用户可以配置多个指标吗？**
A: 可以，一个用户可以配置多个不同的KPI指标。

**Q: 通知人有什么作用？**
A: 通知人会收到该用户的绩效确认通知。

**Q: 生成指标数据有什么用？**
A: 生成后会在月度指标模块中看到该用户对应月份的指标数据。

**Q: 分页状态会保存吗？**
A: 会的，当前页码和每页条数会自动保存到本地存储。
