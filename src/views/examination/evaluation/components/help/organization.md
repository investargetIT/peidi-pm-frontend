# 组织架构 - 使用帮助

## 功能概述
组织架构模块用于管理KPI考核体系中的组织节点树和各节点的指标配置。页面左侧显示组织树形结构，右侧显示选中节点的详情和指标列表。

## 主要功能

### 1. 组织树查看
- 左侧显示完整的组织架构树形结构
- 点击节点可选中并在右侧查看详情
- 支持节点的展开和收起

### 2. 节点管理
#### 添加节点
1. 在左侧树中选择父节点（可选）
2. 点击「添加节点」按钮
3. 在弹出的对话框中填写节点名称等信息
4. 保存后自动刷新树结构

#### 编辑节点
1. 选中要编辑的节点
2. 点击「编辑节点」按钮
3. 修改节点信息
4. 保存后更新

#### 删除节点
> ⚠️ **警告**：删除节点会级联删除其下所有子节点和指标配置，需二次确认！

1. 选中要删除的节点
2. 点击「删除节点」按钮
3. 阅读警告信息并确认
4. 进行二次确认后完成删除

### 3. 指标配置管理
#### 添加指标
1. 选中要配置指标的节点
2. 在右侧详情区点击「添加指标」按钮
3. 在弹出的对话框中配置指标信息
4. 保存后该节点下即有该指标

#### 编辑指标
1. 在右侧指标列表中找到要编辑的指标
2. 点击「编辑」按钮
3. 修改指标配置
4. 保存更新

#### 删除指标
> ⚠️ **警告**：删除指标需二次确认！

1. 在指标列表中找到要删除的指标
2. 点击「删除」按钮
3. 确认删除操作
4. 二次确认后完成删除

## 界面说明
- **左侧**：组织树区域，显示所有节点的层级关系
- **右侧**：详情区域，显示当前选中节点的信息和指标列表

## 常见问题

**Q: 删除节点后能恢复吗？**
A: 不能，删除操作不可逆，请谨慎操作。

**Q: 一个节点可以配置多个指标吗？**
A: 可以，一个节点可以配置多个KPI指标。
