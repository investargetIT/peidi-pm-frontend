# 月度指标 - 使用帮助

## 功能概述
月度指标模块用于查看和管理用户的月度KPI指标数据，支持目标值和完成值的编辑、数据更新、通知用户等功能。

## 界面说明
- **黄色背景**：手填数据行，目标值和完成值都可编辑
- **浅灰色背景的目标值**：自动计算数据的目标值可编辑，完成值不可编辑

## 主要功能

### 1. 搜索筛选
- **负责人**：按用户名搜索（支持拼音匹配）
- **组织路径**：按组织路径搜索
- **月度**：选择要查看的月份（默认为上月）
- **数据类型**：
  - 手填类型
  - 手填类型（未填写完成值）
  - 手填类型（未填写目标值）
  - 自动计算类型
  - 自动计算类型（未填写完成值）
  - 自动计算类型（未填写目标值）

### 2. 表格操作
#### 编辑数据
- **目标值**：所有行都可双击编辑
- **完成值**：仅手填数据行可双击编辑
- 支持 Enter 键确认，Esc 键取消
- 最多保留4位小数

#### 更新指标数据
1. 点击操作列的「更新指标数据」按钮
2. 确认更新操作
3. 系统会执行SQL重新计算该用户的指标数据

#### 提醒填写
1. 点击「提醒填写」按钮
2. 选择月份后发送钉钉待办通知给填写人
3. 24小时内只能发送一次

### 3. 批量操作
#### 批量更新指标数据
1. 选择好月份和筛选条件
2. 点击「批量更新指标数据」按钮
3. 确认批量更新
4. 系统显示更新结果（成功/失败数量及详情）

#### 通知用户确认绩效
1. 点击「通知用户确认绩效信息」按钮
2. 确认发送钉钉通知
3. 通知会发送给当前筛选条件下所有可见的用户

### 4. 数据导出（仅开发者）
- **人事导出**：导出人事格式的报表
- **导出目标业绩表**：导出所选年份1-12月的目标业绩表

## 表格字段说明
- **序号**：按用户分组的序号
- **月份**：数据所在月份
- **负责人**：被考核用户
- **指标名称**：KPI指标名称
- **目标值**：可编辑，双击修改
- **完成值**：手填数据可编辑
- **完成率**：自动计算，根据完成情况显示不同颜色
- **操作**：更新数据、提醒填写

## 完成率颜色说明
- **绿色（优秀）**：完成率 ≥ 100%
- **橙色（良好）**：80% ≤ 完成率 < 100%
- **红色（较差）**：完成率 < 80%

## 权限说明
- 部门负责人可以查看本部门所有用户的数据
- 开发者有导出权限
- 特定用户有手动配置的可见用户列表

## 常见问题

**Q: 为什么有的完成值不能编辑？**
A: 只有手填数据的完成值才能编辑，自动计算数据的完成值由SQL计算生成。

**Q: 完成率是怎么计算的？**
A: 完成率 = 完成值 / 目标值 × 100%（目标值为0时显示"-"）

**Q: 分页状态会保存吗？**
A: 会的，当前页码和每页条数会自动保存到本地存储。
