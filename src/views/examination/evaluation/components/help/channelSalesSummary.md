# 各渠道销售汇总 - 使用帮助

## 功能概述
各渠道销售汇总模块用于查看店铺考核分组的销售汇总数据，按年份和分组展示各月份的销售收款情况。

## 主要功能

### 1. 年份筛选
- 默认显示当前年份的数据
- 可通过年份选择器切换查看其他年份
- 点击「查询」按钮刷新数据
- 点击「重置」按钮恢复为当前年份

### 2. 数据查看
- **分组名称**：店铺考核分组名称
- **月份列**：动态生成有数据的月份列
- **销售收款**：各分组对应月份的销售收款金额
- 金额格式化为人民币格式，保留2位小数

## 表格说明
- 表格按分组展示数据
- 有数据的月份会自动显示为列
- 没有数据的月份不显示
- 金额以千分位格式展示

## 常见问题

**Q: 数据来源是什么？**
A: 数据来自店铺考核分组统计，按分组和月份汇总销售收款数据。

**Q: 可以选择月份吗？**
A: 目前只能按年份筛选，表格会自动显示该年份所有有数据的月份。

**Q: 为什么有些月份没有数据？**
A: 该月份可能没有销售收款记录，系统只显示有数据的月份。

**Q: 可以导出数据吗？**
A: 目前该模块暂不支持导出功能，如有需要请联系管理员。
