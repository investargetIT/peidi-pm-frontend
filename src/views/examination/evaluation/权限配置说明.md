## 5. 月度指标数据权限

**文件**：`src/views/examination/evaluation/components/monthlyIndicators/index.vue`

### 权限规则（查看权）
- **开发者**：看所有人
- **普通用户**：可见人员 = 手动配置人员 + 作为部门负责人可见的部门人员 + 代理继承的范围（见下方 `PROXY_VISIBLE_FROM_USERNAME_MAP`）

### 目标值编辑权（不分手填/自动计算）
- **目标值（元）**：**不分手填还是自动计算**数据，只要行未锁定（`isEdit !== 0`）即可编辑；无需开发者权限
- **完成值**：逻辑不变，仍仅手填数据行可编辑（自动计算数据由SQL生成，不可修改）
- 月份锁定（`isEdit === 0`）优先于上述规则，锁定月份任何人都不能编辑

### 代理继承可见范围（PROXY_VISIBLE_FROM_USERNAME_MAP）

**目的**：让某人直接继承另一个人对月度指标的**完整可见范围**，无需把对方名单抄一遍。

```ts
const PROXY_VISIBLE_FROM_USERNAME_MAP: Record<string, string[]> = {
  梁钰: ["方林霞"] // 梁钰 = 抖音商务（自己负责人）∪ 方林霞负责的抖音电商组
};
```

- 语义：`key` 用户可见范围 = **自身范围**（手动名单 ∪ 部门负责人范围）**∪** `value` 中每个用户的可见范围。
- 当前效果：**方林霞**（抖音电商组负责人）看到本部门全员 12 人；**梁钰**（抖音商务负责人）看到本部门 4 人 **外加**方林霞的抖音电商组 12 人，合计 16 人。
- **自动跟随**：若被代理对象是**部门负责人**（或对方范围来自钉钉部门接口），其成员由接口实时返回，人员增减会自动反映到代理者，无需改代码。
- **支持链式**：A 代理 B、B 代理 C 可一路串联；内部用 `visited` 防环（配置成 A↔B 也不会死循环）。
- **仅影响「能看/能填谁」**：不影响能否进入模块（仍需白名单），也不改变编辑规则（锁定月份、完成值仅手填可编辑）。
- 代理者仍以**自己的账号**填报（是范围继承，不是账号切换）。

## 6. 常见维护

### 新增/修改手动可见人员
修改 `MANUAL_VISIBLE_USERNAME_MAP`：

```ts
用户名: ["可分配的用户1", "可分配的用户2"]
```

### 新增/解除「代理继承」
修改 `PROXY_VISIBLE_FROM_USERNAME_MAP`（值支持多人、支持链式）：

```ts
代理者姓名: ["被代理者1", "被代理者2"]
```

> 取消代理：删除对应那一行即可，无需改动其它任何配置。

> 提醒：代理者本人仍需在**子模块白名单**（`evaluation/index.vue` 的 `COMPONENT_PERMISSION_USER_IDS.monthlyIndicators`）中，否则进不了「月度指标」模块，代理也就不生效。

### 新增部门
修改 `DEPARTMENT_LIST`，添加：
```ts
{ name: "部门名称", deptId: 123456 }
```

### 新增/修改开发者权限

#### 添加核心开发者
在 `CORE_DEVELOPER_USER_IDS` 中添加用户ID：
```ts
const CORE_DEVELOPER_USER_IDS = [
  // ...现有人员
  "新的用户ID", // 新人姓名
];
```

#### 添加普通开发者
在 `DEVELOPER_USER_IDS` 中添加用户ID（如果是核心开发者会自动包含）：
```ts
const DEVELOPER_USER_IDS = [
  ...CORE_DEVELOPER_USER_IDS,
  // ...现有人员
  "新的用户ID", // 新人姓名
];
```

#### 同步维护其它文件
新增开发者时，除月度指标外，请同步确认以下名单是否需要加入：

- `src/views/examination/evaluation/index.vue` 的 `DEVELOPER_USER_IDS`（是否开放「自动化考核」全部子模块）
- `src/views/examination/index.vue` 的 `PERMISSION_ID_LIST.reportExport` / `PERMISSION_ID_LIST.designer`（是否开放「报表导出」「designer」Tab）
- 如需「文件上传」权限，额外加入 `PERMISSION_ID_LIST.fileUpload`
