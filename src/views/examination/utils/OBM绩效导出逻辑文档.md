# OBM 绩效数据财务导出逻辑文档

## 概述

本文档描述 `exportForFinance.ts` 中 `processAndExportOBMData` 函数的完整计算逻辑，用于将 API 数据填充到 Excel 模板并导出。

---

## 一、Excel 列映射关系

| 原列号 | 语义化名称 | 说明 |
|--------|------------|------|
| B 列 | 考核人 (userName) | 用于匹配数据 |
| E 列 | 指标名称 (examinationType) | 用于匹配数据 |
| **I 列 (9)** | **目标累计** | 目标值（累计/当月，视行而定） |
| **K 列 (11)** | **实际值** | 实际完成值（累计/当月，视行而定） |
| **M 列 (13)** | **完成率** | 实际值 / 目标累计 × 100% |
| **O 列 (15)** | **当月目标** | 当月的目标值 |

---

## 二、数据流程

```
1. 读取 Excel 模板
   ↓
2. 删除特定行（第 75 行、第 33 行）
   ↓
3. 调用 API 获取当年全年考核数据
   ↓
4. 逐行处理：匹配 userName + examinationType
   ↓
5. 根据行号范围应用不同计算规则
   ↓
6. 填充目标累计、实际值、完成率、当月目标
   ↓
7. 导出 Excel
```

---

## 三、核心计算逻辑

### 3.1 前置条件

- **当前月份**：`currentMonth`（1-12）
- **上个月**：`previousMonth = currentMonth - 1`
- API 数据包含 `examination[0].data`（目标值数组）和 `examination[1].data`（实际值数组）

---

### 3.2 按行号的计算规则

Excel 模板按行号分为 **三种计算模式**：

| 行号范围 | 计算模式 | I列（目标累计） | K列（实际值） | O列（当月目标） |
|----------|----------|----------------|--------------|-----------------|
| **第 3 行** | 混合模式 | 前 `previousMonth` 个月目标累计 | 上个月实际值 | 前 `currentMonth` 个月目标累计 |
| **第 4-32 行、第 61 行** | 累计模式 | 前 `previousMonth` 个月目标累计 | 前 `previousMonth` 个月实际累计 | 前 `currentMonth` 个月目标累计 |
| **第 33-73 行、第 74-84 行** | 当月模式 | 上个月目标值 | 上个月实际值 | 当月目标值 |

---

### 3.3 完成率计算（M 列）

```
完成率 = (实际值 / 目标累计) × 100%
```

- 保留 2 位小数
- 最小值为 0（如果结果为负）
- 当目标累计为 0 时，完成率为 0

---

## 四、特殊处理规则

### 4.1 侯子洋 - 好适嘉项目净毛利20%

**条件**：
- userName = "侯子洋"
- examinationType = "好适嘉项目净毛利20%"

**处理**：所有月份偏移 **-1**（取上上个月的数据）

| 原规则 | 特殊处理后 |
|--------|------------|
| 前 `previousMonth` 个月 | 前 `previousMonth - 1` 个月 |
| 前 `currentMonth` 个月 | 前 `currentMonth - 1` 个月 |

---

### 4.2 行删除规则

在处理数据前，**从下往上**删除以下行（避免行号变化影响）：
1. 第 75 行
2. 第 33 行

---

### 4.3 未匹配数据处理

当找不到匹配的 `userName + examinationType` 或 `examination` 数据不足时，在四列均填充：
```
"未找到匹配的数据"
```

## 五、辅助函数说明

| 函数名 | 说明 |
|--------|------|
| `toNumber(value)` | 安全转换为数字，null/undefined/NaN 转为 0 |
| `sumDataValue(sum, item)` | 累加数组中 item.value |
| `findObjectByMonthWithFirstDay(array, month)` | 查找月份为 `YYYY-MM-01` 格式的对象 |
| `findObjectByMonthIndex(array, month)` | 查找指定月份在数组中的索引 |

## 六、示例

假设当前是 **6月**（currentMonth=6，previousMonth=5）：

### 示例 1：第 5 行（累计模式）
| 列 | 值 | 计算方式 |
|----|-----|---------|
| 目标累计 (I) | 1000 | 1-5 月目标值之和 |
| 实际值 (K) | 950 | 1-5 月实际值之和 |
| 完成率 (M) | 95.00% | 950 / 1000 × 100% |
| 当月目标 (O) | 1200 | 1-6 月目标值之和 |

### 示例 2：第 40 行（当月模式）
| 列 | 值 | 计算方式 |
|----|-----|---------|
| 目标累计 (I) | 200 | 5 月目标值 |
| 实际值 (K) | 210 | 5 月实际值 |
| 完成率 (M) | 105.00% | 210 / 200 × 100% |
| 当月目标 (O) | 220 | 6 月目标值 |
