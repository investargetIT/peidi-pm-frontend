## 概述

本文档说明如何配置 `exportChannelSales.ts` 中的映射关系和列填充逻辑。

## 二、配置步骤

### 步骤 1：分析Excel模板结构

打开Excel模板，确定以下信息：

| 问题 | 示例答案 |
|------|---------|
| 哪一列是分类名称？ | B列（第2列） |
| 从哪一列开始是月份数据？ | C列（第3列） |
| 月份数据到哪一列结束？ | N列（第14列） |
| 表头行是第几行？ | 第1行 |
| 数据从第几行开始？ | 第3行 |

### 步骤 2：配置分类映射表

打开 `exportChannelSales.ts`，找到 `CATEGORY_MAPPING` 对象，按照以下格式配置：

```typescript
export const CATEGORY_MAPPING: Record<string, string> = {
  // Excel模板中的分类名称: API数据中的groupName
  "天猫旗舰店": "天猫业务单元",
  "京东自营": "京东业务单元",
  "抖音电商": "抖音电商组",
  // ... 更多映射
};
```

**注意**：
- 只有配置在映射表中的分类才会被处理
- 未配置的分类会被跳过（不修改该行数据）
- 配置了映射但API中找不到对应数据的也会被跳过

### 步骤 3：配置列填充逻辑

在 `processAndExportChannelSales` 函数中，找到填充逻辑部分，根据实际Excel模板调整：

```typescript
// 示例填充逻辑 - 请根据实际模板修改
for (let col = 3; col <= 14; col++) { // 假设C到N列是1-12月
  const monthNum = col - 2; // 1-12月
  const monthStr = getFirstDayOfMonth(dayjs().year(), monthNum);
  
  const monthItem = monthData.find((m: any) => m.month === monthStr);
  if (monthItem && monthItem.salesCollection !== undefined) {
    row.getCell(col).value = monthItem.salesCollection;
  }
}
```

## 三、常见场景示例

### 场景 1：简单映射 + 连续月份列

**Excel模板结构**：
- B列：分类名称
- C列：1月
- D列：2月
- ...
- N列：12月

**配置**：
```typescript
export const CATEGORY_MAPPING: Record<string, string> = {
  "分类A": "groupName_A",
  "分类B": "groupName_B",
};

// 填充逻辑
for (let col = 3; col <= 14; col++) { // C-N列
  const monthNum = col - 2; // 1-12月
  const monthStr = getFirstDayOfMonth(dayjs().year(), monthNum);
  const monthItem = monthData.find((m: any) => m.month === monthStr);
  if (monthItem) {
    row.getCell(col).value = monthItem.salesCollection;
  }
}
```

### 场景 2：非连续月份列

**Excel模板结构**：
- B列：分类名称
- D列：1月
- F列：2月
- H列：3月
- ...

**配置**：
```typescript
// 定义列号和月份的映射
const COLUMN_TO_MONTH: Record<number, number> = {
  4: 1,   // D列=1月
  6: 2,   // F列=2月
  8: 3,   // H列=3月
  // ...
};

// 填充逻辑
for (const [col, monthNum] of Object.entries(COLUMN_TO_MONTH)) {
  const monthStr = getFirstDayOfMonth(dayjs().year(), Number(monthNum));
  const monthItem = monthData.find((m: any) => m.month === monthStr);
  if (monthItem) {
    row.getCell(Number(col)).value = monthItem.salesCollection;
  }
}
```

### 场景 3：需要同时填充多个指标

**API数据结构**：
```typescript
{
  groupName: "xxx",
  monthData: [
    {
      month: "2024-01-01",
      salesCollection: 10000,  // 销售收款
      orderCount: 500,        // 订单数
      obmRevenue: 8000        // OBM营收
    }
  ]
}
```

**Excel模板结构**：
- B列：分类名称
- C-E列：1月（销售收款、订单数、OBM营收）
- F-H列：2月（销售收款、订单数、OBM营收）
- ...

**配置**：
```typescript
// 定义列号配置
const COLUMN_CONFIG: Array<{ col: number; month: number; field: string }> = [
  { col: 3, month: 1, field: "salesCollection" },  // C列
  { col: 4, month: 1, field: "orderCount" },       // D列
  { col: 5, month: 1, field: "obmRevenue" },       // E列
  { col: 6, month: 2, field: "salesCollection" },  // F列
  // ...
];

// 填充逻辑
for (const config of COLUMN_CONFIG) {
  const monthStr = getFirstDayOfMonth(dayjs().year(), config.month);
  const monthItem = monthData.find((m: any) => m.month === monthStr);
  if (monthItem && monthItem[config.field] !== undefined) {
    row.getCell(config.col).value = monthItem[config.field];
  }
}
```

## 六、注意事项

1. **备份模板**：修改代码前请先备份Excel模板
2. **列号从1开始**：ExcelJS中列号和行号都是从1开始的
3. **不要强制覆盖**：代码逻辑是"没有匹配就跳过"，不会破坏已有数据
4. **年份处理**：当前默认使用当前年份，如需指定年份可以修改参数
5. **权限控制**：导出按钮只对开发者可见（`isDeveloper()`）
